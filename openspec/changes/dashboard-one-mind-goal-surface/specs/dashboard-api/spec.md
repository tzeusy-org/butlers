## ADDED Requirements

### Requirement: D19 dark surface preserves dashboard-api authority

The specification-only D19 change SHALL leave every existing dashboard-api requirement and scenario normative and unchanged at its existing functional boundary: API schemas, owner authorization, unavailable/partial-source composition, historical identifiers and safe cross-domain reads. It SHALL NOT remove, replace, reinterpret or activate those contracts by adding a dark goal/region interface specification. Goal reads use the single goal ledger. Domain fan-out remains for domain records. Retiring per-unit trigger/MCP proxy use requires its exact owner-approved implementation amendment; descriptive catalog data confers no broker grant.
Any M6 integration SHALL have an allocated complete clause-by-clause amendment and fresh independent semantic review with the actual current capability and active-change owner. A historical body annex, matching scenario name, unchanged count, separate path, green source guard or final owner silence SHALL NOT establish that a future producer or consumer preserves a guarantee.
