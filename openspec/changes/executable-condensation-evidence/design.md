# Evidence protocol and ownership

## Admission

The consumer compares complete before/current test ASTs and source modes under
tests/ and roster/*/tests/. A lost assertion, parameter declaration, fixture or
import remains observable even if a function's qualified name survives. A move
or rename needs a ledger plus complete body, import, fixture, marker and
collected-case continuity. A deleted source file grants no retirement authority.

Evidence binds an exact relevant input inventory, base/head/tree, command,
selection, installed tools/configuration, fresh run nonce, complete case and
phase records, and durable restore state. Duplicate JSON keys, aliases, missing
survivors, nonexact types, partial phases or changed inputs refuse. A freshly
validated protected union can reuse a dated proof only where every relevant
body/mode/selection/tool is unchanged; an event name alone grants no freshness.

## Producer

The producer records real CoverageData arcs for exact opaque per-case contexts
and each setup/call/teardown phase. It uses literal set_query_context, not an
unescaped regular expression or contexts_by_lineno as branch attribution.
Only the owned proof subprocess selects ctrace; ordinary sysmon defaults and
the caller's environment remain unchanged. Raw parameter identities and error
operands remain in RAM; public carriers contain fresh opaque case identities,
fixed failure categories and source coordinates.

Each finite source-owned mutant runs the removed cases and named survivors
against the same restored input. A call assertion failure is a semantic kill
only after successful collection/setup and complete teardown. Timeout,
collection/setup failure, unrelated infrastructure failure, missing output or
unattested restoration is UNKNOWN. Every mutation killed by a removed case
must be killed by a survivor. Protected dogfood needs zero arc residue and no
lost kills. Logging-only waivers require explicit independent per-arc review;
they cannot waive a normative branch.

## Lifetime and inverse

Proof generation owns a fresh output directory and disposable full source
copy, never the live checkout or a peer's tree. Before mutation it durably
journals the exact file bytes/mode and finite command. Each outcome restores
and verifies that input before another mutation. The terminal receipt remains
UNKNOWN until every phase, owned process-group cleanup and restoration has
been admitted. A crash leaves a durable journal and UNKNOWN receipt; recovery
restores only the explicitly owned copy and revalidates source/mode before
restarting. Concurrent proof runs do not share copies or journals.

## Administrative boundary

This active change adds one requirement without modifying existing testing
clauses, IDs, scenarios, preamble or footer. Native generation/application and
physical inverse are rehearsed in disposable input copies. No required guard,
baseline sync, archive or future task mark is earned from that rehearsal.
Genuine preparation review and explicit ROOT release precede supported tracked
administration. Fresh resulting-head review/normal/protected/squash remain
mandatory; a source packet does not complete the original condensation bead.
