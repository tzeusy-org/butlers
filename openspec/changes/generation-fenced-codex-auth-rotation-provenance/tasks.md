## 1. Database contract and role boundary

This packet's proposal/design/deltas are conformed to adopted RFC 0038 D3
before archive. All tasks below remain unchecked future implementation work;
this specification change performs no login, runtime cutover, migration,
deployment, or archive. Source paths identify existing callers to retarget,
not permission to preserve domain-local execution. The goal runner resolves
credentials in the control plane; OAuth sync and login reach the session-host
credential volume through the control plane's service listener and authenticated
control channel. The session host has no database access or inbound dashboard
port; domain daemons never receive goal provider credentials.
