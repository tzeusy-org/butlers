## Mandates

| Governing mandate | Outcomes | Evidence at closeout |
|---|---|---|
| Vision: mental labor reliably absorbed | A–F | Complete synthetic repair loop; no repeated unchanged coding |
| Rule 2: core owns infrastructure | A | QA lifecycle capability and module caller boundary |
| Rules 3–4: sanctioned communication, deterministic sensing, ephemeral reasoning | C–E | Source/checkpoint and bounded admission/inbox contracts |
| Rules 5–6: git identity, runtime tuning and governed scope | A–C | QA prompt/store/model/phase lineage; finite incident work |
| Development/security doctrine and RFC0015: trustworthy, controlled action | B, E, F | Provenance, restricted publisher, human merge, verified recovery |
| Dispatch/single-pane: honest evidence doors | B, F | Existing QA route flows, keyboard access, unknown states |
| Craft and care: observable proportional proof | A–G | Named real seams, exact hosted gates, one closing report |

Rule 1 (single-owner sovereignty) and Rule 7 (connector-owned transport) are preserved: no multi-tenancy or new transport handling is introduced.

No new mandate is inferred for generalist orchestration, pricing, increased concurrency, auto-merge or deployment; these are excluded. The closeout refreshes this mapping against then-current VISION and invokes milestone synthesis for uncovered mandates.
