# Proposed General manifesto and routing amendment

Local successor; not applied to canonical General or Switchboard files. Reconcile exact wording and tool inventory with bu-2jtfw.9 before landing. Owner selected the private direction; exact wording remains unadopted.

## Bounded personal-item memory

> **Remember an identified personal item privately.** Open the private custody screen to select an existing item, record what you observed and confirm it. The screen shows where or with whom you last reported it, when, and the report supporting it. Borrowing, lending, return and retirement remain owner-reported history. We do not infer live physical position.

> Private custody records stay outside model context. Conversation can point you to the private screen but cannot retrieve or repeat its contents. Ordinary messages you send to an assistant retain their normal model-provider exposure; the private screen cannot undo prior disclosure.

## Ownership refusal

> Custody is not a shadow Finance ledger, canonical person registry or Home automation service. Names stay unresolved labels; no receipt proves ownership or custody. General does not move, repair, dispose of, contact anyone about or automatically return an object. Similar objects remain distinct selected items.

## Routing and tools

An owner custody question receives only the fixed `/general/possessions` entry and content-blind capability availability. Do not resolve an item or echo its private label through a custody tool. Item selection, captures, confirmations, receipts, source doors and export happen within the authenticated private screen. Enrollment privately explains that the parent collection and its other items leave generic tool visibility together; private owner access remains. Ordinary tools may later create a separate ordinary collection with the same name; the private screen distinguishes their identities rather than merging them. Private screens cannot attach context to chat. Neither possession_locate nor possession_record is registered as model MCP tooling. No private record parameter is embedded in the generic entry link. Preserve existing Finance, Relationship and Home routing for their ordinary domains without forwarding private custody content. General capture/vocabulary changes remain bu-2jtfw.9-owned.
