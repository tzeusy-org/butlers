## ADDED Requirements

### Requirement: One deterministic source-owned feedback planner
The planner SHALL resolve verified changed paths to current candidate tests through one source-owned trigger catalog and reader registry, preserve configured tests and roster roots and all change-source identities, produce a versioned fail-closed decision with every named reason, and remain feedback planning rather than terminal merge evidence. The complete terminal merge_group population SHALL remain independent of changed paths, advisory weights and planner predictions. The original historical population/count assertions remain provenance and mandatory replay/observer criteria rather than a current-suite identity substitute.

#### Scenario: Exact normalized paths retain their actual source
- **WHEN** a verified branch/index/worktree/untracked union contains renamed, deleted, added and dot-prefixed paths
- **THEN** the plan retains the actual base/head and all contributing sources, preserves leading dots and deduplicates deterministic old/new ownership
- **AND** traversal, missing base and unavailable diff evidence produce FULL with named reasons

#### Scenario: Unknown evidence is not a successful empty plan
- **WHEN** a classifier input, registry, output mode, target or required provenance is missing or malformed
- **THEN** backend applicability and FULL fallback are conservative and the decision is non-empty with precise reasons
- **AND** only a complete audited no-reader resource classification admits NONE

#### Scenario: Local harness residue has a narrow provenance qualification
- **WHEN** known named untracked gate-lock/local-settings residue accompanies an otherwise eligible change
- **THEN** only that explicitly allowed untracked residue is omitted from candidate source classification and its omission is recorded
- **AND** tracked edits at those paths, unknown hidden files and unrelated untracked source remain classified conservatively

#### Scenario: Original full terminal evidence survives
- **WHEN** the event is merge_group
- **THEN** the workflow executes the complete actual adopted unit/integration population, independent preflight and guards under the existing required contexts
- **AND** no scoped success, cached result, weight, docs classification, cancelled job, missing mode or extra-only artifact substitutes for full evidence

#### Scenario: Accepted route folding does not duplicate the planner
- **WHEN** the independently adopted route replaces changes and plan
- **THEN** the same pure planner result is consumed as an independently checked route subresult without restoring a separate costly plan job
- **AND** public setup/service/cache/worker/tracer and frontend topology obligations retain their owners and actual adopted semantics

### Requirement: Complete resource-reader selection precedes a docs skip
The planner SHALL select real Python readers of docs, about, OpenSpec, skills, declared non-executable deployment resources, top-level markdown and frontend resources before authorizing a backend skip. A generated versioned registry SHALL combine auditable literal reads, finite path expressions and explicit dynamic/directory reader declarations. Unsupported read semantics SHALL remain non-successful/UNKNOWN; discovery strings alone SHALL NOT prove arbitrary runtime completeness. Actual undisclosed readers SHALL fail the reader-completeness guard. Conservative unknown-resource selection within an audited complete family SHALL include all declared family readers; unclassified families, executable configuration and stale registries SHALL escalate FULL.

### Requirement: Manifest and roster API exceptions retain exact ownership
The planner SHALL exempt only verified shard-manifest test-path line changes corresponding to test files in the same diff, while retaining actual exact-once, lane, marker, budget and terminal enforcement. Workflow/script and malformed or ownership-changing manifest edits SHALL remain FULL. Roster API edits SHALL select actual tests/api router importers together with the owning roster tests; unresolved dynamic importers SHALL use conservative declared family scope or FULL. Advisory assignment changes SHALL NOT determine the complete lane population.

### Requirement: Current targets and finite affected cost are honest
Every static mapped test target SHALL exist in configured current roots and retain its behavior-bearing survivor. Missing static targets and whole-root widening SHALL escalate to the full matrix rather than execute as a single affected run. Direct changed deleted tests SHALL still collect their legitimate surviving parent. A complete otherwise eligible plan SHALL be admitted only within a finite predicted cost ceiling of at most300seconds and a compatible heavy-shard p90 reference, including measured setup/headroom. Missing/non-finite/incompatible cost evidence SHALL escalate FULL. Advisory estimates SHALL NOT be reported as measured elapsed time or used as lane membership authority. A measured instrumentation species SHALL explicitly distinguish coverage-disabled untraced execution from missing or unknown diagnostics and from active CTracer or SysMonitor. Every actual worker and phase SHALL provide consistent positive instrumentation evidence. An observed hosted runner class SHALL retain source/configuration, source-declared runner label, exact Python, CPU count/affinity, configured and actual worker count and instrumentation policy; every contributing job/file SHALL separately retain its actual CPU model digest and source/run/attempt. A finite maximum over the explicitly observed model set SHALL be labelled an empirical envelope, not identical hardware or an absolute timing guarantee. Missing policy/diagnostics, mixed species, unobserved hardware, changed measured bodies or configuration SHALL yield COST_UNKNOWN and FULL. Candidate generation SHALL NOT authenticate supplied JSON, install a profile, waive the actual 300-second command deadline or satisfy historical/natural delivery thresholds.
