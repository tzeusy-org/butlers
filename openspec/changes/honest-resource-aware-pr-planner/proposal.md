# Honest resource-aware PR planner

## Why

The existing planner contains missing static targets and treats resource-reader
changes as documentation. Historical manifest-only exemptions need real immutable
content, and a small-looking selected scope has no qualified elapsed-cost bound.

## What Changes

Use one conservative source authority, fresh source-bound resource discovery,
verified historical manifest syntax, current targets and a versioned admission
result. Inspect readers before a docs skip. Current affected execution gains
fresh complete configured-root references and independent selected projection.
Unknown ownership, collection or compatible empirical cost stays FULL. Add a
separate default-false hosted measurement source door and uninstalled candidate
builder; no measurement is authorized or claimed by this proposal.

The explicit AC5 alternative is **no wall-clock gain claimed**. All original
four source issues, seven literal acceptance clauses, P1-P7 and S1-S3 remain
binding. Historical frozen145/last100 inputs are retained exactly; future50,
future20 and ten actual affected observations cannot be manufactured by tests.

## Impact

5+6, full lane counts/budgets, dedicated smoke, guards, frontend, go-bridge and
complete protected merge_group remain. Retired live manifests, computed full
