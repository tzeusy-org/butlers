# Design

## Authorities and boundaries

`source_test_map` provides candidate ownership; `scoped_runner` emits one
`pr-test-plan.v1` mode/backend applicability/cost decision. Candidate scope and
paths do not authorize execution. Git NUL status pairs retain actual base/head,
old/new deletion/addition and dirty provenance. Unknown/shared/config/helper and
root-wide targets stay FULL. Only two named untracked harness residues are omitted.

Reader discovery scans current tests, roster, scripts, source helpers and root
conftest without importing them. Literal finite paths over-approximate readers;
unknown IO keeps every family and unproved helper ownership keeps all tests.
Dynamic/no-reader declarations are reviewed source-bound witnesses, never naming
heuristics. Registry drift refuses before route can skip backend tests.

Historical manifests are parsed from immutable Git blobs. Real same-diff test
changes and full physical ownership snapshots are checked; headers/reassignment,
missing/duplicate/traversing entries, dirty inputs or unavailable objects refuse.
This is source eligibility, not current membership, timing or execution evidence.

## Current CI proof

The adopted #4913 hosted selector remains `ci_lanes.py` / pytest-split with five
unit and six integration groups over `.test_durations`. Fresh lane totals and
budgets, dedicated smoke and current fan-in are preserved. Every scoped execution
collects configured roots and selected files before/after under one unchanged
82-minute envelope. The full population projected onto selected canonical files
must equal the independent selected references; the original logical-start,
phase, nonce, config and source execution verifier remains mandatory. A complete
reference is collection evidence and never credits full execution.

## Cost and measurement

The checked profile starts UNKNOWN. A source-reviewed profile needs authenticated
compatible full/affected observations and current heavy-group timing provenance.
Use serial whole-file phase maxima plus complete measured setup/collection/
startup/coordination/finalization overhead; never worker-divide. The ceiling is
min(300 seconds, compatible empirical heavy p90). Only true Git-base-absent new
files may use a labelled maximum-file provisional estimate. Without actual
compatible observation, an otherwise small candidate remains FULL.

The manual default-false main-only source workflow is outside ordinary gates.
Each sequential observation job retains82minutes and existing300-second items.
It does not dispatch itself, publish a profile, or certify labels. ROOT must
authenticate complete job elapsed metadata as well as observer artifacts before
reviewing installation. Pure conformance inputs are never measurements.

## Delivery and verification

All seven original clauses remain open until their named proof exists. Replay
uses exact frozen145/last100 and authenticated original Git heads for eligible
manifest cases. Name-only lists retain their missing identity limitation. Source
eligibility alone is not a SCOPED result. Future50/first20/ten-run observations
remain natural source-bound populations including failures/cancellations and
UNKNOWN results. No savings claim is made. No archive, terminal-gate reduction,
new native authorization or source-admission waiver follows from this change.
