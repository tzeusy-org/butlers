# Spec and Spine -- Capability Specifications

This directory answers **WHAT**: exactly what must be built, expressed as
capability specs with WHEN/THEN acceptance scenarios.

## Documents

| Directory | Question it answers |
|---|---|
| [specs/](specs/) | What are the current, adopted capability contracts (185 spec directories)? |
| [changes/](changes/) | Which capability changes are proposed or in flight (108 active)? |

## Reading Order

1. **specs/** -- start here for the adopted contract for a capability domain.
2. **changes/** -- browse in-flight proposals before they land in specs/.
3. **changes/archive/** -- consult only for history once a change has landed.
