# Butlers Documentation

> **Purpose:** Direct contributors and operators to the maintained documentation.

Butlers is a personal AI agent system: domain specialists handle recurring
work for one owner, coordinated through the Switchboard. Start with the
[documentation index](index.md) for the reading path, setup guides, subsystem
explanations, and operational runbooks.

The [project knowledge map](../about/README.md) identifies the authoritative
homes for doctrine, design contracts, capability specs, topology, and
engineering standards. This directory explains how to understand, run, and
change the system; it does not duplicate those authorities.

Behavior changes update the affected documentation in the same change.
Document contracts, link to their owning specs and interfaces, and replace
stale claims rather than maintaining a second status inventory. See
[documentation maintenance](../about/craft-and-care/review-and-documentation.md#document-lifecycle)
for where new material belongs and when to retire a working artifact.
