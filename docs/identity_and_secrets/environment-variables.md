# Environment Variables

> **Purpose:** The single operator reference for environment variables read by Butlers daemons,
> the dashboard API, and connectors.
> **Audience:** Operators deploying Butlers, developers configuring new integrations.
> **Prerequisites:** [Getting Started](../getting_started/index.md), [Credential Store](../data_and_storage/credential-store.md).

## Overview

Environment variables carry infrastructure bootstrap only: database connection, observability,
process limits, dashboard authentication placement, and connector wiring. Runtime secrets -- API
keys, OAuth tokens, Telegram credentials -- live in the PostgreSQL `butler_secrets` table and are
managed on the dashboard Secrets page; a same-named environment variable is only a last-resort
fallback (see [Resolution Priority](#resolution-priority)).

Each table below names the default the code applies when the variable is unset. Port numbers are
defined once in the [deployment port map](../../about/lay-and-land/deployment.md#port-assignments).
Mounted-file settings (runtime-probe control keys) and dashboard-store credentials (approval
callback keys) are covered in [Environment Configuration](../operations/environment-config.md).

## Database

Read by `src/butlers/db.py` (`db_params_from_env`, `database_name_from_env`).

| Variable | Default | Description |
|----------|---------|-------------|
| `DATABASE_URL` | (none) | libpq-style URL. When set it wins over every `POSTGRES_*` variable, and its path selects the database. |
| `POSTGRES_HOST` | `localhost` | PostgreSQL server hostname |
| `POSTGRES_PORT` | `5432` | PostgreSQL server port |
| `POSTGRES_USER` | `butlers` | PostgreSQL username |
| `POSTGRES_PASSWORD` | `butlers` | PostgreSQL password |
| `POSTGRES_SSLMODE` | (none) | libpq SSL mode, e.g. `require` for a remote database |
| `POSTGRES_DB` | caller-configured | Database name when `DATABASE_URL` is unset |
| `BUTLER_SHARED_DB_NAME` | `butlers` | Database holding the shared credential store |
| `BUTLER_SHARED_DB_SCHEMA` | `public` | Schema of the shared credential store (connectors) |
| `CONNECTOR_BUTLER_DB_NAME` | `butlers` | Database a connector reads its butler-local secret overrides from |

## Observability

| Variable | Default | Description |
|----------|---------|-------------|
| `OTEL_EXPORTER_OTLP_ENDPOINT` | (none) | OTLP HTTP endpoint for traces and metrics, e.g. `http://localhost:4318`. Unset selects a no-op tracer. |

Every process uses one `TracerProvider` and attributes spans per butler via `butler.name` and
`service.name`.

## Runtime

| Variable | Default | Description |
|----------|---------|-------------|
| `BUTLERS_MAX_GLOBAL_SESSIONS` | `3` | Process-wide cap on concurrent LLM sessions across all butlers in the process (`src/butlers/core/spawner.py`) |
| `DASHBOARD_URL` | localhost dashboard | Public dashboard base for owner-facing links generated by daemons; include any reverse-proxy path prefix |
| `ANTHROPIC_API_KEY` | (none) | Dev/test fallback for the API runtime when no key is stored in the credential store |

## Dashboard API

| Variable | Default | Description |
|----------|---------|-------------|
| `DASHBOARD_API_KEY` | (none) | Configured-key mode: non-browser `X-API-Key` or HTTPS key-to-session login. Unset selects passkey enrollment/login; owner authentication is enforced either way. No query-parameter credential is accepted. Mode or key changes require host reconciliation. |
| `DASHBOARD_AUTH_DB_USER` | (none) | Dedicated restricted LOGIN for the authentication store; no fallback to the administrative `POSTGRES_USER`. |
| `DASHBOARD_AUTH_DB_PASSWORD` | (none) | Tier 0 password for that restricted login, supplied only to the dashboard API through deployment secrets; never to browser/runtime children. |
| `DASHBOARD_AUTH_ORIGIN` | (none) | Exact canonical `https://<dns-host>` origin on port 443; no path, wildcard, alias or HTTP fallback. |
| `DASHBOARD_AUTH_RP_ID` | (none) | The same exact DNS hostname, without scheme or path. |
| `DASHBOARD_AUTH_DEPLOYMENT` | `default` | Stable deployment suffix, unique on the origin: lowercase ASCII letters/digits with interior hyphens, at most 32 characters. Scopes cookie names, not browser trust. |
| `DASHBOARD_AUTH_TRUSTED_PROXY_PEERS` | (none) | Comma-separated exact IP addresses of trusted raw ASGI proxy peers. Empty rejects proxy authority; no CIDR or request-derived trust. |
| `DASHBOARD_CORS_ORIGINS` | `http://localhost:41173` | Comma-separated allowed CORS origins |
| `DASHBOARD_STATIC_DIR` | (none) | Built frontend directory (e.g. `frontend/dist/`). When set, the API serves the SPA at `/`. |

See [Dashboard Owner Authentication](dashboard-owner-auth.md) for the authentication model.

## Google OAuth Bootstrap

Needed only to seed the first OAuth flow; afterwards the client credentials live in the database.

| Variable | Default | Description |
|----------|---------|-------------|
| `GOOGLE_OAUTH_CLIENT_ID` | (none) | Google OAuth client ID |
| `GOOGLE_OAUTH_CLIENT_SECRET` | (none) | Google OAuth client secret |
| `GOOGLE_OAUTH_REDIRECT_URI` | `http://localhost:41200/api/oauth/google/callback` | Callback URL registered with Google; must be the dashboard API's public HTTPS URL in a deployed stack |
| `OAUTH_DASHBOARD_URL` | (none) | Where the OAuth callback redirects the browser after success |
| `GOOGLE_MAX_ACCOUNTS` | `10` | Soft limit on connected Google accounts |

## Connectors

Connectors are independent processes that submit events to the Switchboard.

| Variable | Default | Description |
|----------|---------|-------------|
| `SWITCHBOARD_MCP_URL` | (required) | Switchboard MCP SSE endpoint, e.g. `http://butlers-up:41100/sse` in Compose |
| `CONNECTOR_PROVIDER` | per connector | Provider name: `telegram`, `gmail`, `imap`, ... |
| `CONNECTOR_CHANNEL` | per connector | Canonical channel: `telegram`, `email`, ... |
| `CONNECTOR_POLL_INTERVAL_S` | `1.0` | Poll interval in seconds (polling connectors) |
| `CONNECTOR_MAX_INFLIGHT` | `8` | Maximum concurrent ingest submissions |
| `CONNECTOR_HEALTH_PORT` | per connector | Port for `/health` and `/metrics` |
| `CONNECTOR_HEARTBEAT_INTERVAL_S` | `120` | Heartbeat interval in seconds |
| `CONNECTOR_HEARTBEAT_ENABLED` | `true` | `false` disables heartbeats (development) |
| `CONNECTOR_BACKFILL_ENABLED` | `true` | `false` disables backfill polling (Gmail) |
| `CONNECTOR_BACKFILL_POLL_INTERVAL_S` | `60` | How often to poll for backfill jobs (Gmail) |
| `CONNECTOR_BACKFILL_PROGRESS_INTERVAL` | `50` | Report backfill progress every N messages (Gmail) |
| `BUTLER_TELEGRAM_TOKEN` | (none) | Telegram bot token fallback when none is stored |
| `GMAIL_PUBSUB_ENABLED` | `false` | Gmail push notifications instead of polling |
| `LIVE_LISTENER_DEVICES` | (none) | JSON list of live-listener device specs |

Connector-specific variables beyond these are documented in each connector's page under
[Connectors](../connectors/index.md).

## Docker Compose Host Settings

Documented inline in `.env.example` and consumed by `docker-compose.yml` or host scripts:
`ALLOWED_TAILNET_HOSTS` (egress-firewall allowlist, `scripts/egress-firewall.sh`) and the backup
sidecar's `BACKUP_CRON` (default `0 2 * * *`), `BACKUP_RETAIN_DAYS` (default `14`), `BACKUP_DIR`,
and `BUTLERS_BACKUP_DIR`.

## The `.env` File

Copy `.env.example` to `.env` at the repository root and customize:

```bash
cp .env.example .env
```

Every setting in `.env.example` is a commented-out placeholder: database connection, observability,
Google OAuth bootstrap, Compose host settings, and mounted-file paths. Runtime integration secrets
never go in `.env` -- use the dashboard Secrets page.

## Resolution Priority

When a module calls `store.resolve("TELEGRAM_BOT_TOKEN")`
(`src/butlers/credential_store.py` `CredentialStore.resolve`), the order is:

1. Local `butler_secrets` table (butler's own schema)
2. Shared `butler_secrets` table (fallback pool)
3. `os.environ["TELEGRAM_BOT_TOKEN"]` (when `env_fallback=True`)

Dashboard-stored credentials always take precedence over environment variables.

## Verification

```bash
# 1. .env.example ships no live values -- every non-blank line is a comment
grep -vE '^\s*(#|$)' .env.example
# Expected: no output

# 2. POSTGRES_* vars can connect to the database
psql -h "${POSTGRES_HOST:-localhost}" -p "${POSTGRES_PORT:-5432}" \
     -U "${POSTGRES_USER:-butlers}" -d "${POSTGRES_DB:-butlers}" \
     -c "SELECT current_database(), current_user;"

# 3. Unauthenticated dashboard requests disclose no private data
curl -s -o /dev/null -w "%{http_code}" http://localhost:41200/api/butlers
# Expected: 401, or 503 when auth state is unavailable.
# An absent DASHBOARD_API_KEY does not disable the owner boundary.

# 4. Connector variables are present in a running connector
docker compose exec connector-gmail env | grep -E '^(SWITCHBOARD|CONNECTOR)_'
# Expected: SWITCHBOARD_MCP_URL plus any CONNECTOR_* overrides
```
