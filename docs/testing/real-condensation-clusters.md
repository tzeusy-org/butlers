# First real condensation clusters

The first candidate is additive: the original Relationship guardrail owners,
their parameters, helpers and assertions remain in place. The new table uses
one production-built domain app. It checks every currently mounted entity route
against an explicit policy and independently parsed source decorators, refusing
duplicate, remapped or unclassified routes. Domain authentication scaffolding
does not prove owner-auth persistence, deployment or database roles.

For routes using the existing owner-role gate, each forward, reverse and seeded
shuffle run executes non-owner, missing-row and query-error cases. Denial must
occur before data reads or mutation collaborators. The table also checks the
actual owner-filtering SQL text; real PostgreSQL predicate semantics remain a
separate requirement. A healthy archive and missing-entity companion execute
through the same shared app. Overrides, captured app state and the synthetic
auth service are restored after each request; unexpected live Tasks refuse.
Authority-backed identity routes and centrally authenticated domain routes are
classified separately and retain their existing business and authority tests.

The execution request in
`tests/condensation-plans/relationship-owner-route-table.json` names all thirteen
existing non-owner guardrail owners and their additive survivor. Its production
scope is the complete Relationship router. Before deleting, moving or reducing
any protected check, REQ-testing-053 requires the actual complete CTracer,
mutation, restoration, named-survivor and zero-residue account to pass. A
partial batch, timeout or healthy ordinary pytest result grants no retirement.
The unchanged default proof budget is 60 seconds. The complete generator
population is retained, rather than sliced to obtain a passing budget.

This stage claims no wall-clock gain. Historical case counts and test-sum
estimates are motives, not current measurements. Health-facts envelopes, the
complete roster-pool contract, remaining Relationship business cases, full
isolation and timing accounts remain required in the original program.
