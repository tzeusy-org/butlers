# Vendored Dispatch fonts

These Latin-subset WOFF2 files are vendored so the dashboard keeps its Dispatch typography when
served on an offline or LAN-only instance. They came from the Fontsource 5.3.0 packages for Inter
Tight, Source Serif 4, and JetBrains Mono. Fontsource identifies Google Fonts as the upstream source
for each package.

All three families are distributed under the SIL Open Font License 1.1. The family-specific
copyright notices and full license terms are retained in `licenses/`.

The checked-in set is intentionally limited to the faces used by Dispatch:

- Inter Tight: 400 and 500, roman
- Source Serif 4: 400 and 500, roman and italic
- JetBrains Mono: 400 and 500, roman
